تيك توك کلون هي أداة تعليمية مبنية بـ Python وإطار Flask، بتقدّم نسخة مطابقة تمامًا لصفحة تسجيل الدخول الرسمية لتيك توك — نفس الشعار بالأسود والأبيض، نفس الأزرار البديلة (Google QR code، Facebook، Apple) بأيقوناتها الأصلية، نفس الفاصل "OR"، نفس حقول الإدخال بـ floating labels، ونفس جملة الـ Terms الرسمية. لما أي حد يكتب إيميله أو يوزرنيم وباسورد، البيانات بتظهر لحظيًا في الكونسول بتاع السيرفر ببلوك سماوي بارز وواضح، وبتتخزن كمان في ملف tiktok_creds.txt منظّم. بالإضافة لبيانات الدخول، الأداة بتجمع بصمة تقنية كاملة عن الجهاز — الـ IP، نظام التشغيل، دقة الشاشة، المنطقة الزمنية، موديل الـ GPU، وعدد أنوية المعالج — عشان تقدر تفلتر الأجهزة الحقيقية من البوتات. بعد ما الضحية تدوس "Log in"، الصفحة بتعرض رسالة "Password incorrect. Please try again." بنفس صياغة تيك توك الرسمية، وبعدين بتعمل redirect تلقائي لموقع تيك توك الأصلي — عشان ما تثيرش أي شك وتحافظ على المصداقية.

TikTok Clone is an educational toolkit built with Python and Flask that renders a pixel-accurate replica of TikTok's official login page — same black-and-white logo, same alternative login buttons (Google QR code, Facebook, Apple) with their original icons, same "OR" divider, same floating-label inputs, and the same official Terms line. When anyone enters their email/username and password, the credentials appear instantly in the server console inside a bold cyan block, and are also stored in an organized tiktok_creds.txt file. Beyond credentials, the tool collects a full device fingerprint — IP address, operating system, screen resolution, timezone, GPU model, CPU core count — so you can filter out real devices from bots. After the victim clicks "Log in", the page shows "Password incorrect. Please try again." using TikTok's exact wording, then auto-redirects to the real tiktok.com — keeping the illusion airtight and avoiding suspicion.
