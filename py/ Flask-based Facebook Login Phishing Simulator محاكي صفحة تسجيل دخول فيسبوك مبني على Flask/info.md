فيسبوک کлон هي أداة تعليمية مبنية بلغة Python وإطار Flask، بتقدّم نسخة مطابقة لصفحة تسجيل الدخول بتاعة فيسبوك — نفس الشعار، نفس الخط، نفس الألوان، نفس الفوتر والـ languages bar. لما أي حد يكتب الإيميل والباسورد، البيانات بتظهر لحظيًا في الكونسول بتاع السيرفر ببلوك ملوّن وبارز، وبتتخزن كمان في ملف creds.txt منظّم. بالإضافة للبيانات الأساسية، الأداة بتجمع معلومات تقنية عن الجهاز (الـ IP، نظام التشغيل، دقة الشاشة، المنطقة الزمنية، الـ GPU، عدد أنوية المعالج) عشان تقدر تميّز الأجهزة الحقيقية من البوتات. فيه كمان endpoint بسيط (/hits) تشوف منه آخر ١٠٠ محاولة دخول بصيغة JSON. بعد ما الضحية تعمل submit، الصفحة بتعرض رسالة "كلمة المرور غير صحيحة" (مطابقة للحقيقي) وبعدين بتعمل redirect تلقائي لموقع فيسبوك الأصلي — عشان المصداقية ومتبانش مريبة.


Facebook Clone is an educational toolkit built with Python and Flask that renders a pixel-accurate replica of Facebook's login page — same logo, same typography, same colors, same footer and language bar. When anyone types an email and password, the credentials show up instantly in the server console inside a bold, color-coded block, and are also stored in an organized creds.txt file. Beyond basic credentials, the tool collects technical fingerprints from the device — IP address, operating system, screen resolution, timezone, GPU model, CPU core count — so you can separate real devices from bots. A simple /hits endpoint lets you view the last 100 login attempts as JSON. After the victim submits, the page displays a "password is incorrect" error (identical to the real one) and auto-redirects to facebook.com, keeping the illusion intact and avoiding suspicion.
