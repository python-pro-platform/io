WiFi Dump — أداة Python بتستخرج كل شبكات الواي فاي المحفوظة على جهازك (ويندوز، لينكس، ماك) مع الباسورد بتاعها، بدون مكتبات خارجية، وبتنتج ملفات JSON و TXT منظّمة.
Python tool that extracts every saved WiFi network (Windows, Linux, macOS) with its password — no external libraries, outputs organized JSON and TXT files.
