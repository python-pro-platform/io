أداة مكتوبة بلغة Python لأغراض تعليمية، توضح كيفية استخدام مكتبات Python لجمع بعض معلومات الجهاز وإرسالها إلى Telegram Bot عبر Telegram Bot API.
تستطيع الأداة:
قراءة اسم الجهاز ونظام التشغيل.
محاولة قراءة مستوى البطارية.
عرض معلومات أساسية عن التخزين.
التحقق من حالة الاتصال بالشبكة.
البحث عن الصور داخل مجلد التشغيل والمجلدات الفرعية.
إرسال المعلومات والصور إلى Telegram.
⚠️ تنبيه: هذا الكود لأغراض تعليمية فقط، ويجب تشغيله فقط على جهازك أو على جهاز لديك تصريح صريح لاختباره عليه. لا تستخدمه لجمع أو إرسال بيانات أو صور من أجهزة أشخاص آخرين دون علمهم وموافقتهم.

A Python educational tool that demonstrates how Python libraries can be used to collect basic device information and communicate with a Telegram Bot through the Telegram Bot API.
The tool can:
Read the device name and operating system.
Attempt to read the battery level.
Display basic storage information.
Check the network connection status.
Search for images inside the current working directory and its subdirectories.
Send information and images to Telegram.
⚠️ Disclaimer: This code is for educational purposes only. It should only be used on your own device or on a device where you have explicit permission to perform testing. Do not use it to collect or transmit other people's data or images without their knowledge and consent
