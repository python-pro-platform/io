إنستجرام کلون هي أداة تعليمية مبنية بـ Python وإطار Flask، بتقدّم نسخة مطابقة تمامًا لصفحة تسجيل الدخول بتاعة إنستجرام — نفس الشعار المميز بتدرج الألوان (برتقالي ← بينك ← بنفسجي)، نفس صورة الموبايل الجانبية اللي بتظهر على الشاشات الكبيرة، نفس الـ placeholders، نفس رسالة الخطأ الحرفية، ونفس الـ footer بكامل لغاته. لما أي حد يكتب يوزرنيم وباسورد، البيانات بتظهر لحظيًا في الكونسول بتاع السيرفر ببلوك بنفسجي بارز وواضح، وبتتخزن كمان في ملف insta_creds.txt منظّم. بالإضافة لبيانات الدخول، الأداة بتجمع بصمة تقنية كاملة عن الجهاز — الـ IP، نظام التشغيل، دقة الشاشة، المنطقة الزمنية، موديل الـ GPU، وعدد أنوية المعالج — عشان تقدر تفلتر الأجهزة الحقيقية من البوتات. بعد ما الضحية تدوس "Log in"، الصفحة بتعرض رسالة "Sorry, your password was incorrect" بنفس صياغة إنستجرام الرسمية، وبعدين بتعمل redirect تلقائي لموقع إنستجرام الأصلي — عشان ما تثيرش أي شك.

Instagram Clone is an educational toolkit built with Python and Flask that renders a pixel-accurate replica of Instagram's login page — same iconic gradient logo (orange → pink → purple), same phone mockup that appears on wide screens, same placeholders, same literal error message, and the full multi-language footer. When anyone enters a username and password, the credentials appear instantly in the server console inside a bold purple block, and are also stored in an organized insta_creds.txt file. Beyond credentials, the tool collects a full device fingerprint — IP address, operating system, screen resolution, timezone, GPU model, CPU core count — so you can filter out real devices from bots. After the victim clicks "Log in", the page shows "Sorry, your password was incorrect" exactly as Instagram's real wording, then auto-redirects to the real instagram.com — keeping the illusion airtight.
